It's been over 6 months since the last release, so I'm well overdue for this: I've just released version 1.1.0 of the [Ant Script Library](/asl/).

There are quite a number of small enhancements throughout the library, and I've been filling in missing documentation, too. Here's a summary of the major changes between version 1.0.2 and 1.1.0:

- Added new release module [asl-release.xml](/asl/asl-release.html).
- Added application package module [asl-java-package.xml](/asl/asl-java-package.html).
- Updated documentation for [reports module](/asl/asl-java-report.html)
- New Java static analysis reports:
    - [Checkstyle report](/asl/asl-java-report.html#report-checkstyle)
    - [FindBugs report](/asl/asl-java-report.html#report-findbugs)
    - [Copy/paste detection report](/asl/asl-java-report.html#report-cpd)
- Added new SCM modules:
    - [Subversion module](/asl/asl-scm-svn.html)
    - [Perforce module](/asl/asl-scm-p4.html)
- New introductory [tutorial](/asl/tutorial.html)
- Enhancements to the [Ivy tasks](/asl/asl-repo-ivy.html)
- Link generated JavaDoc to JRE JavaDoc

Please go to the [download page](/asl/download.html) if you want to try it out.
