This is fairly old news, but I was absolutely fascinated by the "secret" Microsoft documents [Evangelism is War](http://edge-op.org/iowa/www.iowaconsumercase.org/011607/3000/PX03096.pdf). I think it's a very clear insight into why Microsoft is so successful, as well as why they are viewed abhorred in some circles.

Hat tip to [Steve Loughran](http://www.1060.org/blogxter/entry?publicid=ACFB34A604794311360E3D3B1F274522).

#### Update (Monday, 5th March)

As a number of you have mentioned, the link above to the Evangelism is War article is now invalid. The pdf was hosted on a website called [Iowa Consumer Case](http://www.iowaconsumercase.com/), which contained all the public domain court documents from the _Comes vs Microsoft_ case. The entire website is now password protected, as reported on [The Register](http://www.theregister.co.uk/2007/02/20/microsoft_missing_archive/) a couple of weeks ago. Apparently, Groklaw is collecting all the documents on the page [Comes v. Microsoft Exhibits](http://www.groklaw.net/staticpages/index.php?page=2007021720190018), but the Evangelism is War page doesn't appear to be there yet. If anyone knows the location of this document, sent me an email. In the meantime, a good summary can be found on Amy Stephen's article "[State of Iowa Consumers sue Microsoft for Acts of Antitrust](http://community.nebraska.edu/amyblog/index.php/2007/01/20/state-of-iowa-consumers-sue-microsoft-for-acts-of-antitrust/)".
